# 三国·霸业 —— 手机端文字策略游戏

> 一局制三国题材文字策略：**从零起家，经营一城，派工建造，出兵相邻之城，一统天下 36 城。**
> 移动优先，纯文字 + 数值，无广告无内购，单机离线可玩。

**直接玩：** 打开 `https://<你的用户名>.github.io/<仓库名>/` （手机浏览器体验最佳）

---

## 玩法

| 维度 | 设计 |
|---|---|
| **时间** | 「内政」实时累积（每秒产出）；「天下」按 **旬** 推进，**一旬 = 10 分钟**真实时间。所以它是**半挂机**：挂着攒资源，回来做决断 |
| **目标** | 占领全部 **36 座城**。没有转生、没有多周目，输赢只有一次 |
| **开局** | 只有难度选择（1~5）+ **自己挑一座开局城**。开局 **0 武将** —— 从"无名之辈"起家，日后才招得到关张 |
| **三根支柱** | **经营壮大** ｜ **攻城** ｜ **收集武将** —— 一切机制都服务这三根 |
| **决断** | 军报会带着选项找上门，过期走默认处置。不逼你即时操作 |

### 你会做的事

- **建造**（30 种建筑）：民居出劳力与研究点、农田出粮、兵营出驻军上限、仓廪/木场/钱库抬资源上限……
  每种资源都会「顶格浪费」，所以建上限建筑是事实上的主线
- **派工**：把劳力塞进农夫/樵夫/石匠/矿工/工匠/商贾/书生 7 种岗位
- **研究**（60 项科技，内政/军事/谋略各 20）
- **征兵 → 编队（可带参军）→ 出征**：相邻进攻 1 旬；跨城增援按跳数
- **武将**：招揽 / 战俘招降 / 劝降归附；忠诚会掉，**叛变前有预告**；名将阵亡不可复生
- **外交**：送礼 / 停战 / 同盟 / **劝降** / 宣战 / 背刺。AI 是纯实力政治
- **委托太守代管**：城多了以后，交给太守按方针自动建造与派工（效率随政治提升）

### 战斗与战报

```
输出 = 数量 × 攻 × 克制 × 地形 × (1 + 主将统率/200)
损失 = 输出 ÷ (有效防御 × 2 + 20)
```

**战报逐回合可复盘**：双方出输、损失、除数（有效防御）都给出，你能自己算一遍——
「可复盘」是这个设计里不可让的东西。

## 技术

- **引擎**：纯 ESM、零依赖、无 DOM 依赖（Node 可跑、可做自动化测试）
- **界面**：Svelte 5 + Vite 6，移动优先 390×844，长按出详情、无 hover 依赖
- **数据驱动**：`data/*.json` 11 张表，改数值不用碰代码
- **存档**：单自动档 + 导出的存档码（Base64，带校验和）。**不做多存档位、不做铁人**
- **确定性**：seed 驱动 RNG，同种子可完整复现

发布版（本仓库）是**已构建的静态产物**，不需要 Node，任何现代浏览器直接打开。
