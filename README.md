# 三国·霸业

手机端三国文字策略游戏。开局只有一座城、没有一个武将，从无名之辈起家，经营、征兵、攻城、收人，最后占满全图。

## 怎么玩

打开网页就是开局页：选难度、选一座开局城。

- **时间**：内政实时产出，天下按「旬」推进（一旬 = 10 分钟真实时间）。挂着攒资源，回来做决断。
- **三件事**：经营城（建造 / 派工 / 研究）｜打仗（征兵 / 编队 / 出征）｜收武将（招揽 / 招降 / 劝降归附）。
- **城多了可以委托太守**：按方针自动建造与派工，省手。
- **军报会带着选项找上门**，过期按默认处置，不逼你守在屏幕前。
- **目标**：占满全图。没有转生，输了就结束。

## 操作

- 点底部标签切换各个面板，长按条目看详情。
- 顶栏 `×1 / ×2 / ×5 / ×10` 调速，`跳旬` 立刻结算本旬。
- 存档是单自动档（每旬自动保存）；换设备或清缓存前，在「政 → 存档」**导出存档文件**备份。
